# AniLibria TV — ТЗ

Неофициальный клиент AniLibria для Android TV. Причина появления: официальный `app-tv`
(anilibria/anilibria-app) работает со старым API, поэтому авторизация и избранное в нём сломаны.
Этот клиент целиком построен на новом API v1 (`https://anilibria.top/api/v1`).

Целевое устройство: Ugoos SK4 (Android 14, arm64, пульт). Визуальный ориентир — официальный app-tv:
тёмный фон, крупные постеры в горизонтальных рядах, текст о выбранном релизе вынесен над/под рядами.

## Экраны и функции

### F1. Авторизация (обязательно рабочая)
- Вход **по коду (основной)**: `POST /accounts/otp/get {device_id}` → показываем крупно 6-значный
  код и QR на страницу `https://aniliberty.top/app/auth/otp/linkDevice` (код в URL страница не
  принимает — пользователь вводит его вручную; текст-подсказка с адресом рядом с QR).
  Пользователь, залогиненный на сайте, вводит код (`/accounts/otp/accept` делает сайт). ТВ раз в 3–5 сек опрашивает `POST /accounts/otp/login {code, device_id}` до
  получения токена или истечения кода; по истечении — кнопка «Новый код».
  `device_id` — UUID, генерируется один раз и хранится в DataStore.
- Вход **по логину/паролю**: `POST /accounts/users/auth/login {login, password}`.
- Токен хранится в DataStore, подставляется как Bearer. Профиль: `GET /accounts/users/me/profile`.
- Выход: `POST /accounts/users/auth/logout` + очистка токена.
- Гость может смотреть всё, кроме избранного/синхронизации.

### F2. Главная
Ряды сверху вниз (порядок согласован с пользователями 2026-10-05: «Новые эпизоды» — первым):
1. **Уведомление «Вышло в избранном»** (см. F6) — текстовый блок, если есть что показать.
2. **Новые эпизоды** (главный ряд, «поток что вышло», как на сайте) — `GET /anime/releases/latest`
   (`limit` ~30), порядок по `fresh_at` desc. Постеры 2:3 крупно, на карточке бейдж «Серия N»
   (`latest_episode.ordinal`) и «N ч назад» (`fresh_at`); бейдж-сердечко, если релиз в избранном.
   OK по карточке — карточка релиза (с пульта прямой запуск серии оказался неудобен — отзыв
   пользователей 2026-10-05; во всех рядах и в ленте OK = карточка).
   Заголовок ряда «Новые эпизоды ›» открывает экран-ленту (сетка, подгрузка при прокрутке).
3. **Продолжить просмотр** (F8) — если есть незавершённые серии.
4. **Выходит сегодня** — `GET /anime/schedule/now` → `today`, постеры, номер ожидаемой серии.
5. **Выходит завтра** — `tomorrow` оттуда же.
6. **Избранное** (если авторизован).
Боковое/верхнее меню: Главная, Поиск, Избранное, Расписание, Профиль/Вход, Настройки.

### F3. Карточка релиза
`GET /anime/releases/{idOrAlias}`: постер, названия, год/сезон/тип, жанры, описание, статус,
день выхода. Кнопки: «Смотреть / Продолжить с N серии», «В избранное / Убрать», «Торренты».
Список серий (номер, название, превью, отметка просмотрено/прогресс).

### F4. Плеер
Media3 ExoPlayer, HLS (`hls_480/hls_720/hls_1080` в эпизоде). Выбор качества (по умолчанию —
последнее выбранное, запоминаем). Перемотка D-pad ±10 с, удержание — ускоренная.
**Пропуск опенинга/эндинга**: у эпизода есть `opening`/`ending` {start, stop} — когда позиция
внутри интервала, показываем кнопку «Пропустить опенинг»/«Пропустить эндинг» с фокусом. Опция
две независимые опции — «Автопропуск опенинга» и «Автопропуск эндинга» (обе по умолчанию выкл.;
каждый отрезок пропускается автоматически один раз за серию). Настройки плеера (качество, скорость,
автопропуски, ночной режим) — в отдельном боковом меню по ⚙ / долгому OK / Menu; в нижней панели —
только управление воспроизведением.
**Автопереход** к следующей серии в конце с обратным отсчётом 5–10 с.
Сохранение прогресса: локально + `POST /accounts/users/me/views/timecodes` (каждые ~15 с,
на паузе и на выходе), `is_watched=true` при досмотре ≥90 %.

### F5. Избранное
`GET/POST /accounts/users/me/favorites/releases`, добавление/удаление —
`POST`/`DELETE /accounts/users/me/favorites` с телом `[{release_id}]`. Список `ids` кэшируем,
чтобы на карточке сразу знать состояние. Экран избранного: сетка постеров, сортировка.

### F6. Уведомление при входе
При старте приложения (авторизован): берём избранное, для каждого релиза сравниваем последнюю
вышедшую серию с сохранённой в прошлый раз (DataStore: releaseId → последний известный ordinal).
Новые — показываем текстовым списком «Название — серия N» поверх главной (диалог/баннер,
закрывается Back/OK) и строкой на главной. После показа запоминаем новое состояние.
Первый запуск только запоминает состояние, ничего не показывает.

### F7. Поиск
`GET /app/search/releases?query=` с debounce 400 мс, экранная клавиатура TV, результаты сеткой.
Голосовой поиск — через системный ввод, если доступен. Последние запросы — локально.

### F8. Продолжить просмотр
Источник: `GET /accounts/users/me/views/timecodes` (если авторизован) + локальная история.
Ряд на главной: релиз, серия, прогресс-бар. Нажатие — открыть плеер с позиции.

### F9. Торренты
`GET /anime/torrents/release/{releaseId}`: список раздач (серии, качество, кодек, размер, сиды/личи,
дата). Действие «Открыть в TorrServe»: Intent с magnet (`ACTION_VIEW`, `Uri.parse(magnet)`),
приоритет пакетам TorrServe (`ru.yourok.torrserve`), иначе системный chooser; если обработчика
нет — показать magnet текстом/QR. Дополнительно «Скачать .torrent» не нужно.

### F10. Расписание недели
`GET /anime/schedule/week`: вкладки по дням недели (сегодня по умолчанию), постеры.

### F11. Канал «Watch Next»
Публикация «Продолжить просмотр» в системную строку Watch Next Android TV
(`androidx.tvprovider`). Некритично, делается последним.

### F12. Автообновление
Проверка `https://api.github.com/repos/feskolech/anilibria-androidtv/releases/latest` при старте
(не чаще раза в 6 ч): если `tag_name` > versionName — диалог «Доступна версия X», скачивание APK
в cache и установка через `PackageInstaller`/FileProvider (`REQUEST_INSTALL_PACKAGES`).

### Настройки
Качество по умолчанию, автопропуск опенинга, автопереход, зеркало API, выход из аккаунта, версия.

## Управление с пульта
Минимальный пульт: D-pad, OK, Back, Home (цифр и медиа-кнопок может не быть). Любая функция
доступна только через D-pad/OK/долгий OK/Back; медиа-кнопки и цифры — бонус, если есть.
Плеер (оверлей скрыт): ◀/▶ перемотка ±10 с (удержание ускоряет 10→30→60 с), OK пауза,
▲ оверлей (качество, скорость, аудио, «Следующая серия»), ▼ лента серий, долгий OK — быстрое
меню, Back — скрыть оверлей / выйти с сохранением прогресса. Бонус: Play/Pause, ⏭⏮ соседняя серия,
⏩⏪ перемотка, цифры — переход к серии N, Menu — быстрое меню.
Списки/карточки: долгий OK — контекстное меню (избранное, списки, торренты, карточка).

## Публичный релиз
Проект публикуется на GitHub для всех. Поэтому: никаких личных адресов/ключей в коде (всё
настраиваемое — через BuildConfig/настройки), UI на русском (по умолчанию) и английском
(`values-en`), README на ru/en с дисклеймером «неофициальный клиент», LICENSE в корне,
скриншоты в README. Отчёты о падениях — только с согласия. Поддерживать разные ТВ-боксы:
не полагаться на GMS, на конкретную плотность экрана, на наличие медиа-кнопок; работать на
armeabi-v7a/arm64-v8a/x86 (без нативных библиотек).

## Нефункциональные требования
- Холодный старт до главной ≤ 3 с на SK4; постеры с кэшем Coil (диск ≤ 200 МБ).
- Без Google Play Services (на ТВ-боксах их может не быть).
- Подписанный release APK собирается в GitHub Actions по тегу `v*` и прикладывается к Release.
