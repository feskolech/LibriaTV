## T01 — API-клиент v1 `[x]`
- `data/api`: Retrofit-интерфейсы и DTO для: schedule/now, schedule/week, releases/latest,
  releases/{idOrAlias}, releases/episodes/{id}, app/search/releases, torrents/release/{id},
  otp/get, otp/login, auth/login, auth/logout, me/profile, me/favorites (ids, releases GET, add,
  delete), me/views/timecodes (GET, POST). Сверять поля с `docs/api/openapi-v1.json`.
- OkHttp: Bearer-interceptor (токен из TokenStore), User-Agent `AniLibriaTV/<version>`,
  логирование только в debug, таймауты 15 с, fallback на зеркало aniliberty.top при IOException.
- `TokenStore` и `DeviceIdStore` на DataStore.
- Domain-модели и мапперы; утилита абсолютного URL для картинок.
- Unit-тесты с MockWebServer на парсинг: schedule/now, release с эпизодами (opening/ending, hls_*),
  torrents, otp/get, auth/login, ошибка 401/422. Фикстуры — реальные ответы API
  (можно скачать curl'ом публичные эндпоинты; приватные — составить по схеме).
- Приёмка: тесты зелёные; никакого UI.

## T03.1 — Правки главной `[x]`
- При переходе фокуса на нижние ряды верхние ряды уезжают ПОД инфо-блок (описание релиза) и
  видны обрезками постеров. Инфо-блок — фиксированная шапка; список рядов — отдельная область
  под ней с `clipToBounds`, ряд в фокусе прокручивается к верху этой области.
- Между описанием (2 строки) и заголовком первого ряда — нормальный отступ (≥16dp).
- Светлая вертикальная полоса слева от контента (фон под свёрнутым меню) — убрать: фон-постер
  либо на весь экран под меню, либо меню с непрозрачным фоном, без полосы.

## T11b — Автообновление, экран настроек, индикатор загрузки `[x]`
- Автообновление по SPEC F12: `UpdateChecker` (GitHub API `repos/${BuildConfig.UPDATE_REPO}/releases/latest`,
  не чаще раза в 6 ч, время последней проверки в DataStore; сравнение semver `tag_name` без `v` с
  `BuildConfig.VERSION_NAME`; ассет — первый `*.apk`). Диалог на главной «Доступна версия X» с
  заметками релиза (body, обрезать) и кнопками «Обновить» / «Позже». Скачивание через OkHttp в
  `cacheDir/updates/` с прогрессом, установка через FileProvider + `ACTION_VIEW`
  (`application/vnd.android.package-archive`), `REQUEST_INSTALL_PACKAGES`; если
  `canRequestPackageInstalls()` = false — открыть `ACTION_MANAGE_UNKNOWN_APP_SOURCES` для нашего пакета
  и объяснить текстом. Ошибки сети — молча (проверка необязательная). Unit-тесты на сравнение версий
  и выбор ассета (фикстура JSON релиза).
- Экран «Настройки» (пункт меню уже есть, сейчас заглушка): качество по умолчанию (480/720/1080 —
  то же значение, что запоминает плеер), «Пропускать опенинг автоматически», «Автопереход к следующей
  серии», зеркало API (anilibria.top / aniliberty.top — сохранять и применять в OkHttp без перезапуска),
  «Проверить обновления» (принудительно, с результатом), версия приложения, ссылка на GitHub (текстом/QR).
- Плеер не трогать (T12 сделан). В «Настройки» добавить переключатели из `PlaybackStore`:
  синхронизация частоты кадров (`frameRateMatch`), ночной режим (`nightMode`), скорость по умолчанию.
