Первая публичная бета LibriaTV — неофициального клиента AniLibria для Android TV на новом API v1.

**Что умеет**
- Вход в аккаунт по коду с телефона или по логину и паролю
- Главная: новые эпизоды, «Продолжить просмотр», что выходит сегодня и завтра, рекомендации
- Уведомление о новых сериях в избранном и канал на главном экране Android TV
- Избранное и списки («Смотрю», «Запланировано» и другие), своя оценка
- Каталог с фильтрами, поиск (в том числе голосовой), расписание на неделю
- Плеер 480/720/1080p: пропуск опенинга и эндинга, скорость, таймер сна, ночной режим звука,
  автопереход к следующей серии; прогресс синхронизируется с аккаунтом
- Торренты через TorrServe с выбором серии внутри раздачи
- Пульт с телефона по QR-коду
- Темы (тёмная, OLED), 6 цветов акцента, размер интерфейса 90–130 %
- Автообновление из GitHub Releases

Это бета: возможны ошибки. Пишите о них в Issues — приложите модель приставки и что делали.

**Установка:** скачайте `LibriaTV-0.1.0-beta.1.apk` ниже и поставьте на приставку
(флешка + файловый менеджер, Send Files to TV или `adb install`). Нужен Android 7.0+.

---

First public beta of LibriaTV, an unofficial AniLibria client for Android TV built on the v1 API:
code or password sign-in, new-episodes feed, favorites and lists, catalog, search, schedule,
a remote-friendly player with opening/ending skip and progress sync, TorrServe torrents,
phone remote, themes and self-update. Expect bugs — please report them in Issues.
