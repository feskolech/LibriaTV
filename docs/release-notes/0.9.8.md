**Новое**
- «О приложении»: в «Что нового» — коротко о текущей версии и кнопка «Подробнее» с историей всех версий.
- «Проверить обновления» сообщает, что установлена актуальная версия (или что проверить не удалось).

**Исправления**
- Меню больше не дёргается при открытии карточки аниме.
- Карточка, открытая из каталога (избранного, поиска…), относится к этому разделу: в меню выбран он,
  а не «Главная», и на медленной приставке приложение больше не перескакивает на «Главную».
- «Назад» из карточки возвращает фокус на ту карточку, которую открывали (главная, каталог).
- Плеер: фокус не пропадает при нажатии «влево» на первой кнопке или «вверх» с полосы прогресса.
- Плеер: кнопки предыдущей/следующей серии не скрывают панель управления.

**New**
- About: a short "What's new" for the installed version and a "More" button with the full version history.
- "Check for updates" says when the latest version is installed (or when the check failed).

**Fixes**
- The side menu no longer twitches when a release page opens.
- A release page opened from the catalog (favorites, search…) belongs to that section in the menu,
  and a slow box no longer jumps to Home.
- Back from a release page returns to the card it was opened from (home, catalog).
- Player: focus no longer disappears on Left at the first button or Up from the progress bar.
- Player: previous/next episode buttons keep the controls on screen.
