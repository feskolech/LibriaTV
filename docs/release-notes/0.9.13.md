**Новое**
- Новая карточка аниме: одна главная кнопка «Смотреть» / «Продолжить», остальные действия — значками (избранное, список, оценка, торренты) с подписью под фокусом. Описание крупнее и занимает место над кнопками, полный текст — по OK на описании.
- Серии длинных сериалов разбиты на диапазоны по 50 («1–50», «51–100»…) над сеткой номеров: до нужной серии пара нажатий. Сбоку — кадр, название и прогресс выбранной серии.
- После последней серии плеер закрывается и возвращает на карточку аниме.
- Окна описания и истории версий стали шире.

**Исправления**
- Меню больше не открывается само после быстрого перелистывания и выбора раздела.
- Если зажать «Вверх» в меню, оно больше не закрывается.
- Досмотренная серия начинается сначала, а не с конца.
- В поиске курсор встаёт в конец введённого текста (в том числе после голосового ввода).

---

**New**
- A new release page: one main "Watch" / "Continue" button, the other actions as icons (favourites, list, rating, torrents) with the focused one's name below. The description is larger and fills the space above the buttons; OK on it opens the full text.
- Long series show their episodes as ranges of 50 ("1–50", "51–100"…) over a grid of numbers: any episode is a few presses away. The focused episode's frame, title and progress are shown alongside.
- After the last episode the player closes and returns to the release page.
- The description and version history dialogs are wider.

**Fixes**
- The menu no longer reopens by itself after scrolling through it quickly and choosing a section.
- Holding Up in the menu no longer closes it.
- A watched episode starts over instead of resuming at its end.
- In search, the cursor goes to the end of the text (including after voice input).
