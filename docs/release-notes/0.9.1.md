**Что нового**
- Приложение теперь называется клиентом AniLiberty (бывш. AniLibria): в мае 2025 года фандаб-команда
  и сайт стали AniLiberty, а имя AniLibria осталось у студии официального дубляжа. Каталог тот же.
  Основной адрес по умолчанию — aniliberty.top, anilibria.top остаётся запасным.
- Пульт с телефона защищён надёжнее: в QR-коде теперь одноразовый случайный ключ, а PIN нужен только
  при ручном вводе адреса; подбор PIN ограничен, запросы принимаются только из домашней сети.
- Перед установкой обновления приложение проверяет, что скачанный файл — это LibriaTV, подписанный
  тем же ключом, и что версия новее.
- В «Что нового» показывается только текст на языке интерфейса.

---

**What's new**
- The app now describes itself as an AniLiberty (formerly AniLibria) client: in May 2025 the fandub
  team and the site became AniLiberty, while the AniLibria name stayed with the official dubbing studio.
  Same catalog; aniliberty.top is now the default host, anilibria.top the fallback.
- Safer phone remote: the QR code carries a random one-time key, the PIN is only for typing the address
  by hand, PIN guessing is limited and only home-network requests are accepted.
- Before installing an update the app checks that the file is LibriaTV, signed with the same key, and newer.
- "What's new" shows only the text in the UI language.
